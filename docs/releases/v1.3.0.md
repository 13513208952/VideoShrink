# VideoShrink 1.3.0 — unified release

This is the first unified VideoShrink release. The Windows, Linux and Android applications are now
developed and distributed from one repository and are published together under a single tag.

**Nothing was rebuilt for this release.** Every package below is the exact artefact that its
platform project built and published; source code was not modified during the merge.

## Packages

| Platform | App version | Minimum requirements | Asset |
|---|---|---|---|
| Windows | 1.0.1 | Windows 10/11, x64 | `VideoShrink-v1.0.1-win-x64.zip` |
| Linux | 1.0.1 | Linux x64, glibc 2.28+ | `VideoShrink-linux-x64-v1.0.1.tar.gz` |
| Android | 1.2.0 | Android 10+, arm64 | `VideoShrink-Android-1.2.0-arm64-release-debug-signed.apk` |

### Windows

Portable build — extract the zip and run `VideoShrink.exe`. `ffmpeg.exe` and `ffprobe.exe`
(GPL build) are bundled under `tools/`, so no separate installation is required.

### Linux

Extract the tarball and run `VideoShrink` from the extracted directory. The archive bundles
pinned static `ffmpeg` / `ffprobe` binaries under `tools/`.

### Android

Sideload the APK (`adb install …` or open it on the device). The build is arm64-only and is signed
with the Android debug certificate — suitable for personal sideloading and testing, not for store
distribution.

## Android native artefacts

The Android app links a custom FFmpeg build. Because that binary is not tracked in git, the exact
native artefacts and matching source archives are attached here as well:

| File | Purpose | SHA-256 |
|---|---|---|
| `libvideoshrink_ffmpeg-arm64-v8a.so` | Native FFmpeg PIE linked by the APK (byte-identical to the library inside the 1.2.0 APK) | `00db2e48…3dd2b86` |
| `ffmpeg-8.1.2-source.tar.gz` | Corresponding FFmpeg source (LGPL-2.1-or-later build) | `188f256d…37d9f4f` |
| `svt-av1-4.2.0-source.tar.gz` | Corresponding SVT-AV1 source (BSD-3-Clause-Clear) | `e09d636f…393dd2b86` |

Build configuration and the exact commits are documented in
[`android/docs/native-build.md`](https://github.com/13513208952/VideoShrink/blob/master/android/docs/native-build.md).

## Verify your download

Download `SHA256SUMS.txt` next to the package(s) and run:

```sh
sha256sum -c SHA256SUMS.txt
```


The development history of each original repository is preserved in this repository
(`git log` of the merge commits for `linux/` and `android/`, `git log --follow` per file for
